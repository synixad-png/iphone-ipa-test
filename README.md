# iphone-ipa-test

Testowa aplikacja SwiftUI na iPhone. Projekt wymaga iOS 16+, buduje niepodpisany IPA ARM64 na macOS przez GitHub Actions. Workflow uruchamia się po push do main lub ręcznie. Artefakt zawiera IPA, raport walidacji oraz SHA-256.

Instrukcja instalacji: README.txt. Wynik kompilacji należy potwierdzić w Actions.
